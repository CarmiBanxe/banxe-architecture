# M1.14 — read-only **catalogue meta surface** (counts + version) (PLAN, docs-only)

<!-- Source: docs/migration/M1.14-catalogue-meta-surface.md | Date: 2026-06-18 | Lane: BANXE.RAR → EMI | Server-only (ADR-103) -->

## Status

**PLAN only — no code, no tests, no ADR, no ledger shard in this step.** Next lowest-blast-radius
**advisory** subtrack after M1.13 (asset→markets reverse-xref), **not greenfield**. The xref grid
(single / list / reverse) is exhausted; M1.14 adds a read-only **catalogue meta** summary: a small
endpoint reporting **derived counts** (symbols / instruments / markets / assets) + the existing
package **version** + `source`. Read-only, **no live money/orders/balances/fees/infra metrics**.

## Domain selection (why this, not the alternatives)

- **Catalogue meta surface — CHOSEN.** It is the most read-only, money-/regulatory-furthest step:
  counts are **derived** from the already-migrated list functions; version reuses the existing
  `__version__`. No new data, no second registry/counter source.
- **fee-schedule descriptor — deferred.** Only admissible as reference/metadata; risks proximity to
  `FeeEnginePort` semantics. Not now.
- **KYC/AML — deferred** (compliance gate).
- **Internal ops metrics are NOT in scope.** `/internal/health/dse-baas` + `/internal/metrics/dse-baas`
  are `include_in_schema=False`, infra-fenced, Prometheus/readiness — M1.14 must **not** touch,
  duplicate, or expose them. M1.14 is a **public advisory catalogue-meta** (counts/version only),
  with **no infra/secret/PII metrics**.

## 1. Scope

**Legacy area:** none new — M1.14 summarises the already-migrated catalogues. **EMI seam (derive):**
new public read-only endpoint (e.g. `GET /api/v1/catalogue/meta`) returning a small derived meta
DTO (e.g. `CatalogueMeta`): integer counts `symbols` / `instruments` / `markets` / `assets`
(computed from `list_symbols()` / `list_instruments()` / `list_instrument_asset_xref()` /
`asset_catalog()`), the existing package `version` (`__version__`), and `source` (sandbox-mock).
Existing `/symbols`, `/instruments`, `/instruments/{symbol}`, `/instruments/{symbol}/assets`,
`/markets`, `/assets/{asset}/markets`, `/assets/metadata`, and the internal ops routes unchanged.
The new DTO is a **derived summary** (like `AnalyticsContext`), not a data SoT. Exact path/shape
decided in the M1.14 deep-read (step 0).

## 2. Numeric Invariants (I-01)

- The only numerics are **integer meta counts** (cardinalities of existing catalogues) — **NOT
  balances, amounts, positions, prices, or computed fees.** `version`/`source` are strings. No
  `Decimal`/`BigNumber`/`float` money values are introduced; **no fee computation**.

## 3. Activation Safety

- **Advisory / mock layer ONLY**, derived read-only summary — **NO live orders, execution,
  balances, positions, payments, fee computation, or fund movement; NO infra/secret/PII metrics.**
- No live catalogue/exchange calls, no network/keys, no prod wiring beyond an additive public route;
  default sandbox-mock; **fail-closed** — counts derive from the existing fail-closed list functions
  (a malformed catalogue entry is already skipped upstream); never a fabricated count.

## 4. Duplication Audit (ADR-102) — MANDATORY before any M1.14 code

1. Repo-wide search for any catalogue meta/counts/version-summary endpoint — esp. `api/symbols.py`,
   `api/assets.py`, `api/sandbox.py` (`/status`), `api/internal.py` (ops health/metrics),
   `app.py` (root `/` health + `__version__`), `instruments/params.py`/`xref.py`, `assets/catalog.py`.
2. **Canonical SoTs (reuse/derive, do NOT duplicate):** symbol universe `SymbolInfo`/`MarketDataPort`/
   `list_symbols`; instruments `_INSTRUMENT_PARAMS`/`list_instruments`; markets bundle
   `list_instrument_asset_xref`; assets `_ASSET_META`/`asset_catalog`. **Version source:** existing
   `banxe_trading_backend.__version__` (reused; **not** a second version constant). M1.14 **derives**
   counts and **reuses** version — **no second registry, counter-source, or version constant**.
3. **Internal ops observability** (`/internal/*`, `BaasMetrics`, `dse_baas_health`) — **keep,
   untouched, not duplicated, not exposed publicly.**
4. **`FeeEnginePort` = fee SoT** — not touched/duplicated.
5. Source-of-truth + every consumer; keep/merge/delete + risks; doubt → fail-closed + escalate.

### Frozen contracts (must not break)
`SymbolInfo`, `InstrumentInfo`, `MarketDataPort`, `FeeEnginePort`, `CryptoAssetMetadata`,
`InstrumentAssetXref`, `__version__`, and the M1.6–M1.13 contracts (`EarnMetrics`,
`AnalyticsContext`, `EarnRatesResponse`, earn statement, accounts metadata, `AssetCatalogResponse`,
`list_instruments`/`instrument_asset_xref`/`list_instrument_asset_xref`/`markets_for_asset`).

## 5. Out-of-scope (strictly NOT in M1.14)

- **All P0 / regulated / live parts:** live orders, execution, balances, positions, payments,
  fund movement, live catalogue/exchange operations.
- **Fee computation / billing / preview** (`FeeEnginePort`/`/fees/preview`).
- **KYC/AML**, cards, crypto-wallet ops.
- **Internal/ops/infra metrics, readiness, Prometheus, secrets, PII** — explicitly excluded; the
  `/internal/*` surface is not touched/exposed.
- **No new data catalogue/registry, no second version/counter source, no enrichment of frozen DTOs.**
- **No user migrations, no DB migrations, no schema changes, no live state machines.**
- **No contract-breaking changes**; the meta surface is an additive derived summary.
- **No ADR, no code, no tests, no ledger shard in THIS planning step.**
