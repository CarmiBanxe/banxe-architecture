# M1.13 — asset → markets **reverse cross-reference** (PLAN, docs-only)

<!-- Source: docs/migration/M1.13-asset-markets-reverse-xref.md | Date: 2026-06-18 | Lane: BANXE.RAR → EMI | Server-only (ADR-103) -->

## Status

**PLAN only — no code, no tests, no ADR, no ledger shard in this step.** Next lowest-blast-radius
**advisory** subtrack after M1.12 (markets bundle), **not greenfield**. A read-only **reverse
projection** over the existing markets bundle: `GET /assets/{asset}/markets` →
`list[InstrumentAssetXref]`, the markets whose **base or quote** is the given asset. Read-only,
**no live money/orders/balances/fees**.

## Domain selection (why this, not the alternatives)

- **`GET /markets/{symbol}` single view — REJECTED (duplicate).** `GET /instruments/{symbol}/assets`
  (M1.11) **already** returns the `InstrumentAssetXref` for one symbol — i.e. the single-symbol
  market view already exists. A `/markets/{symbol}` path would duplicate it (same DTO, same data),
  violating the ADR-102 no-duplication discipline. Not pursued.
- **asset → markets reverse xref — CHOSEN.** There is **no** reverse lookup ("which markets does
  this asset trade in"). It is a genuinely new projection, composes existing sources, introduces
  **no new DTO** (reuses `InstrumentAssetXref`), and stays far from money.
- **health/meta surface — deferred.** Off the markets/instrument/asset seam; revisit later.
- **fee-descriptor / KYC-AML — deferred** (FeeEnginePort / compliance gate).

## 1. Scope

**Legacy area:** none new — M1.13 filters the M1.12 markets bundle by asset. **EMI seam
(reverse projection):** new read-only endpoint `GET /api/v1/assets/{asset}/markets` →
`list[InstrumentAssetXref]`, assembled by a new `markets_for_asset(asset)` that reuses
`list_instrument_asset_xref()` and keeps entries whose `base_asset.asset` or `quote_asset.asset`
equals the normalized asset. Existing `/markets`, `/symbols`, `/instruments`,
`/instruments/{symbol}`, `/instruments/{symbol}/assets`, `/assets/metadata` unchanged. **Reuses
`InstrumentAssetXref` — no new DTO/catalogue/registry.** Exact path/shape decided in the M1.13
deep-read (step 0).

## 2. Numeric Invariants (I-01)

- Only existing fields are surfaced (via `InstrumentAssetXref`): instrument `tick_size`/`min_qty`/
  `max_qty` (`DecimalString` trading params) + asset `display_decimals` (int). **NOT balances,
  amounts, positions, or computed fees.** No `BigNumber`/`float`; **no fee computation**
  (`FeeEnginePort` owns it; only `fee_schedule_ref` string is carried).

## 3. Activation Safety

- **Advisory / mock layer ONLY**, a read-only filter/projection — **NO live orders, execution,
  balances, positions, payments, fee computation, or fund movement.**
- No live catalogue/exchange calls, no network/keys, no prod wiring beyond an additive route;
  default sandbox-mock; **fail-closed** — an asset with no matching markets returns an **empty
  deterministic list** (never a fabricated market); the code-step may additionally `404` an asset
  outside the known universe. No fabricated entries.

## 4. Duplication Audit (ADR-102) — MANDATORY before any M1.13 code

1. Repo-wide search for any asset→markets / reverse-xref endpoint or assembler — esp.
   `instruments/xref.py` (`InstrumentAssetXref`/`instrument_asset_xref`/`list_instrument_asset_xref`),
   `instruments/params.py`, `assets/catalog.py`, `models.py` (`split_symbol`), `api/symbols.py`,
   `api/assets.py`.
2. **Canonical SoTs (reuse, do NOT duplicate):** markets bundle = `list_instrument_asset_xref`/
   `InstrumentAssetXref`; instrument params = `_INSTRUMENT_PARAMS`/`instrument_info`; asset metadata
   = `_ASSET_META`/`asset_metadata`; symbol universe = `SymbolInfo`/`split_symbol`. M1.13 **filters/
   projects** them — **no second catalogue, registry, params table, or DTO**; it reuses
   `InstrumentAssetXref`.
3. **Confirmed:** `GET /instruments/{symbol}/assets` already covers the single-symbol view —
   M1.13 must **not** add a duplicate `/markets/{symbol}` path.
4. **`FeeEnginePort` = fee SoT** — not touched/duplicated.
5. Source-of-truth + every consumer; keep/merge/delete + risks; doubt → fail-closed + escalate.

### Frozen contracts (must not break)
`SymbolInfo`, `InstrumentInfo`, `MarketDataPort`, `FeeEnginePort`, `CryptoAssetMetadata`,
`InstrumentAssetXref`, and the M1.6–M1.12 contracts (`EarnMetrics`, `AnalyticsContext`,

## 5. Out-of-scope (strictly NOT in M1.13)

- **All P0 / regulated / live parts:** live orders, execution, balances, positions, payments,
  fund movement, live catalogue/exchange operations.
- **Fee computation / billing / preview** (`FeeEnginePort`/`/fees/preview`); only `fee_schedule_ref`.
- **KYC/AML**, cards, crypto-wallet ops.
- **No new DTO** (reuse `InstrumentAssetXref`); **no new catalogue/registry/params**; **no
  duplicate `/markets/{symbol}` path**; **no enrichment of frozen DTOs**.
- **No user migrations, no DB migrations, no schema changes, no live state machines.**
- **No contract-breaking changes**; the reverse view is an additive filter over existing data.
- **No ADR, no code, no tests, no ledger shard in THIS planning step.**
