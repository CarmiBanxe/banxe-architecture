## A. Scope — ENABLE, not build (ADR-102 reuse)

S6.2-EN makes the **already-built** dYdX MarketDataPort adapter serve **sandbox-live** public market data (instead of the in-memory mock), gated behind flags, with **mock retained as the CI/default**. It is **enable-not-build**: no new adapter, no new port, no rebuild.

### ADR-102 reuse-map

| Artifact | Decision | Note |
|---|---|---|
| `ports/dydx_market_data.py` (dYdX v4 Indexer adapter) | **REUSE — do NOT rebuild** | built (ADR-083 S6.2); maps Indexer → §D2 envelope unchanged; API-only, no key; I-01 Decimal validation. |
| `ports/market_data_port.py` (`MarketDataPort` Protocol + mock) | **REUSE — do NOT rebuild** | the §D2 contract `{type, data:{bids,asks,sequence}}` (IL-195) — **unchanged**. |
| in-memory mock feed | **REUSE — keep as CI default** | deterministic; remains the fail-closed fallback. |
| **flag-gate / provider-selection wiring** | **NET-NEW (minimal)** | per `dse-live-providers-options.md` the `BANXE_DSE_PROVIDER_MODE` / `BANXE_DSE_LIVE_ALLOWED` gate is *"future-spec — not implemented."* S6.2-EN wires this **config-as-data** selection (mock ↔ dydx) — the only net-new code; **no adapter logic.** |

So S6.2-EN = **reuse the adapter + wire the (small) flag gate that routes to it**, mock-default and fail-closed.

## B. Flag / config (exact env vars; verified from `dse-live-providers-options.md`)

| Flag | mock (CI / default) | sandbox-live (this sprint) | Notes |
|---|---|---|---|
| `BANXE_DSE_MARKET_PROVIDER` | *(unset / `mock`)* | `dydx` | provider selector (`dydx \| kaiko`) |
| `BANXE_DSE_PROVIDER_MODE` | `mock` *(enforced today)* | `sandbox-live` | overall mode `mock \| sandbox-live \| prod-live` |
| `BANXE_DSE_LIVE_ALLOWED` | unset / `false` | `true` | **master kill-switch** — non-mock requires `true` **and** mode ≠ mock (else fail-closed to mock) |
| `BANXE_DSE_MARKET_BASE_URL` | — | dYdX **public Indexer** base URL | config-as-data; public endpoint, no secret |
| `BANXE_DSE_MARKET_API_KEY` | — | **NOT used for dydx** | key is *kaiko-only*; dYdX Indexer is keyless |

- **Mock stays the CI/default.** sandbox-live activates **only** when `BANXE_DSE_LIVE_ALLOWED=true` **and** `BANXE_DSE_PROVIDER_MODE=sandbox-live` **and** `BANXE_DSE_MARKET_PROVIDER=dydx`.
- **Fail-closed:** any of those unset/false, or provider error → **fall back to the mock** (never hard-fail, never silently serve stale).
- All thresholds/timeouts/rate-limits/hostname allow-list = **config-as-data** (Configuration-over-Hardcoding 30.N+1.9), not literals.
- **No secrets** introduced — dYdX Indexer is public/keyless. (`BANXE_DSE_MARKET_API_KEY` stays unused here.)

## C. Provider binding — dYdX v4 Indexer → §D2 envelope (unchanged)

- **API-ONLY (AGPL):** consume the **public** dYdX Indexer over the network (REST + `v4_orderbook` WS) via generic HTTP/WS libs. **No dYdX/AGPL code vendored or self-hosted** → no §13 trigger (ADR-140 / ODR-4: API-only is the accepted mode). No keys/secrets/wallet for this read-only step.
- **Mapping (built, reused):** REST snapshot `GET /orderbooks/perpetualMarket/{ticker}` → `{bids,asks}`; WS `v4_orderbook` batched diffs → `{bids?,asks?}` (`size "0"` = delete). dYdX `price`→§D2 `price`, `size`→§D2 `quantity`.
- **Sequence:** dYdX has no per-message sequence on this channel → the adapter **synthesizes a strictly-increasing `sequence`** (snapshot, then +1 per diff), satisfying §D2's monotonic rule (FE drops `diff.sequence ≤ snapshot.sequence`). **Unchanged from the built adapter.**
- **I-01:** Indexer emits decimal strings; the adapter **validates each parses as Decimal (never float)** and passes through (`_to_decimal_str`). Atomic/decimal strings end-to-end.

## D. Advisory-moat compliance

S6.2-EN is **read-only market data only**:
- **No order placement, no execution, no custody, no keys, no signing.** (Order placement is S6.4-EN, Phase-2 ODR-gated.)
- Consumed by the **DSE advisory** path: market data → advice → unsigned intent → client wallet signs. The backend never holds keys, never executes autonomously (ADR-083 self-custodial; ADR-089/090/091 advisory seams).
- Public market data → **non-custodial, no PII, no Travel-Rule, no MiCA execution surface** at this read-only step.

## E. Acceptance criteria + conformance-test plan

**Acceptance:**
- [ ] Flag gate wired: `dydx`+`sandbox-live`+`LIVE_ALLOWED=true` routes to the built dYdX adapter; **any other combination = mock**.
- [ ] **Mock remains the CI/default** — existing `tests/test_dydx_market_data.py` + the MarketDataPort suite stay green with no live network in CI.
- [ ] **Fail-closed:** provider error / unreachable Indexer / kill-switch off → **fall back to mock**, logged; never a hard 5xx, never stale-silent.
- [ ] No new adapter logic, no key, no secret, no §D2-contract change (FROZEN).
- [ ] config-as-data for base URL / timeouts / rate-limit / hostname allow-list.

**Conformance tests (extend `tests/test_dydx_market_data.py`; no live calls in CI):**
1. **Selection** — flag matrix resolves provider correctly (dydx only under the full sandbox-live+kill-switch combo; mock otherwise).
2. **Envelope** — dYdX snapshot/diff fixtures map onto the §D2 `{type,data:{bids,asks,sequence}}` envelope **unchanged**.
3. **Sequence/snapshot-on-gap** — synthesized sequence is strictly increasing; a simulated gap/reconnect re-seeds from snapshot (stale diffs dropped). *(The deeper re-snapshot-on-reconnect robustness was the former S6.7 "hardening" TODO — S6.7 is now DROPPED per ADR-094; the minimal monotonic-sequence + snapshot-reseed conformance is in-scope here, deeper hardening is a separate future concern, not a sandbox-live blocker.)*
4. **I-01** — every price/size validated as Decimal; no float in the path.
5. **Fail-closed** — provider exception → mock fallback asserted; kill-switch off → mock.
6. **Coverage** — suite stays green at the repo's `--cov-fail-under` gate.
