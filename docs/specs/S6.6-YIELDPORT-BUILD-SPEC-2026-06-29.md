## 0. Why this spec exists (the ADR-102 refinement)

The road map marked S6.6 *"`ports/yield_port.py` absent → genuine build."* True for the **port file** — but a **full earn/yield advisory module already exists** in `banxe-trading-backend` and **must be reused, not rebuilt** (ADR-102). Verified by read-only deep-read (2026-06-29):

| Already built (REUSE — do NOT rebuild) | What it is |
|---|---|
| `earn/providers.py` — `EarnRatesProvider` Protocol (`async get_earn_metrics(asset) -> EarnMetrics`), `MockEarnRatesProvider`, `build_earn_provider(name)` factory (`"mock"` default; `"crypto-earn"`; real = operator-gated `ValueError`) | the **advisory rates** seam (yield scenario per asset) |
| `earn/rates.py` — `EarnRatesCatalog` Protocol, `RateCard`/`EarnRatesResponse` (`CamelModel`, `DecimalStr`), `RiskBand` enum, `_RATES_DISCLAIMER`, `SANDBOX_MOCK` source flag | the **rate-card / comparison** surface (`GET /v1/earn/rates`) |
| `earn/{crypto_earn,statement,status,taxonomy}.py`, `api/earn.py`, `earn-api.yaml`, `dse-baas-risk-earn.md` + 7 earn tests | catalogue, status, statement, taxonomy, BaaS facade |
| `dse.models.EarnMetrics` (`current_yield_pct`, `protocol`, `chain`, `lockup_days`, `variable_rate`, `risk_summary`) | the advisory metrics model |

**Net-new (BUILD):** only the **unsigned staking-tx construction** layer — the StakeKit/Yield.xyz adapter that turns an advisory yield into an **unsigned intent** the client signs. This is the missing "unsigned-intent" piece of the earn vertical, parallel to `dydx_exchange.py` (orders) and `lifi_quote.py` (swaps).

**Advisory-moat trajectory (canonical):**
`earn/` advisory rates *(advice)* → **YieldPort builds an unsigned staking tx** *(unsigned intent)* → **client wallet signs & submits** *(execution)*. Backend **never holds keys, never signs, never submits** (live submission is a later operator-gated sub-sprint).

## 2. Contract — `ports/yield_port.py` (mirror `quote_port.py` + `dydx_exchange.py`)

Mirror the house pattern exactly: module docstring (ADR ref + self-custodial note), `@runtime_checkable Protocol`, a deterministic `Mock…Adapter` as the CI/dev default, models from `banxe_trading_backend.models`, **Decimal/atomic-unit integer strings (I-01, never float)**, env-gated real provider.

### 2.1 Protocol

```python
@runtime_checkable
class YieldPort(Protocol):
    """List advisory yields and CONSTRUCT an unsigned staking intent.

    Self-custodial: the backend NEVER signs, holds keys, or submits. It returns
    an UNSIGNED staking transaction intent the client wallet signs (S6.3/S6.4).
    """

    async def list_yields(self, request: YieldListRequest) -> YieldListResponse: ...
    async def build_stake_intent(self, request: StakeIntentRequest) -> StakeIntent: ...
    async def build_unstake_intent(self, request: UnstakeIntentRequest) -> StakeIntent: ...
```

- `list_yields` **delegates to the injected `EarnRatesProvider` / `EarnRatesCatalog`** (reuse). It does **not** invent rate data.
- `build_stake_intent` / `build_unstake_intent` return an **unsigned** `StakeIntent` (the tx params the wallet signs) — mirror `dydx_exchange.py`'s "construct unsigned order intent" pattern.

### 2.2 Mock adapter (default; no network, no keys)

```python
class MockYieldAdapter:
    """Deterministic in-memory YieldPort — NO network, NO keys. Default for CI/dev."""
    def __init__(self, earn_provider: EarnRatesProvider | None = None) -> None:
        self._earn = earn_provider or build_earn_provider("mock")
    # list_yields -> wraps self._earn.get_earn_metrics(...) into YieldListResponse
    # build_stake_intent -> deterministic unsigned StakeIntent (atomic-unit strings)
```

### 2.3 Models (add to `banxe_trading_backend.models`, `CamelModel`/`DecimalStr`)

- `YieldListRequest{ assets?: list[str] }` · `YieldListResponse{ yields: list[YieldOption], source, as_of, disclaimer }` (reuse `RateCard`/`EarnMetrics` shape — wrap, don't fork).
- `StakeIntentRequest{ asset, amount (atomic str), protocol?, chain? }` · `UnstakeIntentRequest{ ... position_ref }`.
- `StakeIntent{ asset, amount, protocol, chain, unsigned_tx: dict, kind: "stake"|"unstake", provider: "mock", disclaimer }` — `unsigned_tx` is an **opaque unsigned payload** the client signs; backend never populates a signature.

### 2.4 Error hierarchy (mirror `exchange_port.py`)

Reuse the established pattern: `YieldError` (base) → `YieldUnavailable`, `ValidationError`, `ComplianceBlock`. Map provider/network failure → `YieldUnavailable`; bad asset/amount → `ValidationError`.

## 3. Configuration / gating (enable-not-build; fail-closed)

| Flag | Default | Effect |
|---|---|---|
| `BANXE_YIELD_PROVIDER` | `mock` | `mock` → `MockYieldAdapter`; `stakekit` → **operator-gated** (raise `ValueError` "not wired" until S6.6-EN, mirroring `build_earn_provider`) |
| `BANXE_DSE_LIVE_ALLOWED` | unset/false | master kill-switch — any non-mock provider **must fail-closed** unless this is true **and** mode ≠ mock (mirror `dse-live-providers-options.md`) |
| `BANXE_EARN_PROVIDER` (existing) | `mock` | the wrapped earn-rates provider; YieldPort passes through, never overrides |

`build_yield_provider(name)` factory mirrors `build_earn_provider`: `"mock"` wired; anything else raises `ValueError("... operator-gated; only 'mock' is available")`.

## 4. Invariants & boundaries (hard)

- **I-01 Decimal/atomic units** — amounts are integer atomic-unit **strings**, never float (stronger than upstream float SDKs, per `dydx_exchange.py`).
- **Self-custodial** — backend holds **no user private keys**, **never signs**, **never submits**. `unsigned_tx` only.
- **API-only / licensing** — StakeKit SDK is **MIT** over a **hosted REST** API (ADR-083); no AGPL vendoring concern (unlike dYdX). Live calls env-keyed, operator-gated.
- **Advisory disclaimer** — reuse `earn/rates.py` `_RATES_DISCLAIMER` wording (MiCA/MiFID: analytics, not execution; not a promise of return).
- **No FROZEN-contract change** — `EarnRatesProvider`/`EarnRatesCatalog`/`EarnMetrics`/`RateCard` consumed **unchanged** (wrap only).
- **ADR-102** — `list_yields` reuses the earn seam; re-implementing rate data in YieldPort is a violation.

## 5. Conformance-test plan (`tests/test_yield_port.py`, mirror `test_ports.py`)

1. **Structural** — `MockYieldAdapter` satisfies `YieldPort` (`isinstance`, `@runtime_checkable`); all three methods callable/async.
2. **Reuse** — `list_yields` returns data sourced from the injected `EarnRatesProvider` (assert `source` is sandbox-mock; assert it matches `MockEarnRatesProvider.get_earn_metrics`).
3. **Unsigned intent** — `build_stake_intent` returns a `StakeIntent` with a non-empty `unsigned_tx`, **no signature field**, atomic-unit string `amount`, `provider="mock"`; deterministic for fixed input.
4. **I-01** — amounts are integer strings; no float anywhere in the path.
5. **Fail-closed** — `build_yield_provider("stakekit")` raises `ValueError` when `BANXE_DSE_LIVE_ALLOWED` is unset; `BANXE_YIELD_PROVIDER=stakekit` does not activate a live path.
6. **Errors** — bad asset → `ValidationError`; simulated provider failure → `YieldUnavailable`.
7. **Coverage** — keep the suite green at the repo's existing `--cov-fail-under` gate.
