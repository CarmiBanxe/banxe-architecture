## A. Scope — wire, not build (ADR-102 reuse)

S6.8 closes the **FE↔BFF loop over the MOCK feed**: the front-end renders the order-book and places **unsigned** order intents against the **mock** ExchangePort. It is **enable/wire-not-build** — both ends already exist; no new ports, no new repo.

### ADR-102 reuse-map

| Artifact | Decision | Note |
|---|---|---|
| backend `api/orders.py` | **REUSE** | order intent endpoint (mock-default) |
| backend `ports/exchange_port.py` + `ports/dydx_exchange.py` | **REUSE — do NOT rebuild** | ExchangePort + dYdX adapter; **mock-default** |
| backend `services/intent_preview.py` | **REUSE** | builds the **unsigned** order-intent preview |
| FE `src/shared/api/trade-proxy.ts` + `ws-client.ts` (:8080) | **REUSE — do NOT rebuild** | the FE proxy/WS client to wire to the BFF |
| deterministic mock feed (IL-185) | **REUSE — keep CI default** | preserved as the CI/default feed |
| **the wiring** (FE proxy ↔ BFF REST/WS contract binding) | **NET-NEW (thin)** | connect existing FE client to the existing BFF surface; no new logic in either |

⇒ S6.8 = **bind the two existing surfaces over mock**, nothing rebuilt.

---

## B. Wiring

- FE `trade-proxy.ts` (:8080) ↔ backend **BFF REST/WS** surface (the existing `api/orders.py` + market-data WS from S6.2-EN).
- FE **renders the order-book** from the mock market-data feed (the S6.2-EN feed, mock-default).
- FE **places an order** → backend returns an **unsigned order intent** (`intent_preview.py`) → surfaced to the **client wallet** to sign. The backend **signs nothing, holds nothing**.
- All money/quantity fields = atomic-unit/decimal strings (I-01, never float), unchanged across the wire.

---

## C. Invariants

- **Mock-default / fail-closed:** the mock feed + mock ExchangePort are the CI/default; any live path stays off. No flag here enables a live venue (that is S6.4-EN).
- **No keys, no live venue, no ODR, no RED-zone live execution** — S6.8 is mock-only.
- **Deterministic mock feed (IL-185)** preserved as CI default — tests run with no live network.
- Two-repo (FE + backend), **no new repo, no new ports**, config-as-data for the BFF base URL/port (§10).
- Egress: only the local BFF surface; no external venue calls.

---

## D. Advisory-moat compliance

- Order = **unsigned intent** surfaced to the client wallet; **client signs every order**; backend never signs, never holds keys, never executes autonomously (ADR-083 self-custodial; advisory seam).
- Mock feed → no real funds, no custody, no execution, no PII at this step.

---

## E. Acceptance criteria + conformance-test plan

**Acceptance:**
- [ ] FE order-book renders from the mock market-data feed (S6.2-EN feed, mock-default).
- [ ] FE "place order" round-trips to the BFF and receives an **unsigned** order intent (no backend signing).
- [ ] **Mock stays CI/default** — existing FE + backend suites green, no live network in CI.
- [ ] **Fail-closed:** BFF unreachable / mock error → FE degrades safely (no silent live fallback, no signed order).
- [ ] No new ports, no keys, no live venue, no §D2/contract change.

**Conformance tests (extend existing FE + backend suites; no live calls in CI):**
1. **Order-book render** — mock feed → FE store renders bids/asks (§D2 envelope unchanged).
2. **Unsigned-intent round-trip** — FE place-order → BFF → `intent_preview` returns an unsigned intent; assert backend produced **no signature**.
3. **I-01** — money/quantity decimal strings survive the FE↔BFF round-trip, no float coercion.
4. **Fail-closed** — BFF/mock error → FE safe-degrade asserted; no live path, no signed order.
5. **CI default** — both suites green on the deterministic mock (IL-185), no network.
