# ADR-172: Governed Autonomy Ladder L0–L4 + HITL threshold policy

**Status:** Proposed (DRAFT / NOT FOR MERGE — операторский HITL; закрывает часть OD-R21)
**Date:** 2026-07-18
**Numbering note:** номер выделен локально (следующий после ADR-171); Central подтверждает при merge.
**Relation:** расширяет ADR-128 (HITL-матрица L1–L3 авторитетов) клиентски-ориентированной лестницей автономии агентов; не заменяет HITL-MATRIX.yaml.

## Context

ADR-128 задаёт уровни человеческого надзора по типам решений, но не задаёт **прогрессию автономии агента по мере накопления evidence**. Концепт-корпус ([PLAN-CONCEPT] intent-layer-launch) определяет 5-уровневую лестницу; запуску (launch slice) нужен канон: что разрешено на каждом уровне и когда уровень повышается.

## Decision

Принять лестницу как канон Intent Layer:

| Уровень | Название | Разрешено | HITL |
|---|---|---|---|
| L0 | Advisory | только информация/анализ | нет |
| L1 | Alert | уведомления/предложения | нет |
| L2 | Supervised | операции ТОЛЬКО с подтверждением (confirmation card) | всегда |
| L3 | Conditional | auto low-risk по BPR-правилу; high-risk → человек | по правилу |
| L4 | Delegated | широкая автономия в scope_limits | аномалии + monthly SMF evidence review |

- **Launch slice = максимум L2.** L3 — только после запуска, поэтапно, по явному BPR-правилу на каждый intent_type. L4 — только при действующем monthly evidence review (Grafana drift + SMF-подпись).
- Порог повышения уровня = операторское решение (I-27), никогда автоматика.
- Привязка: уровень фиксируется в паспорте агента и в `ClientIntentRecord.linked_agent_id` → проверяется compliance overlay до исполнения.

## Consequences

**Positive:** явный, аудируемый путь роста автономии; EU AI Act Art.14-совместимость; продуктовый trust-нарратив. **Negative/costs:** каждый переход L2→L3 требует BPR-правила и операторского акта — медленнее «свободной» автономии (сознательный выбор).

## Alternatives considered

(а) Единый глобальный уровень автономии на агента без per-intent-type правил — отвергнуто: не масштабируется по риску; (б) автоматическое повышение по метрикам — отвергнуто: нарушает I-27.
