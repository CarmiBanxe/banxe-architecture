## Fable5 banking-canon verdict (ШАГ 1 — advisory, зафиксирован)

- **Вердикт: ПОДТВЕРЖДЕНО с двумя корректирующими оговорками (C1, C2). Confidence = 0.92** (≥0.90 —
  авто-вердикт допустим; ратификация оператором остаётся обязательной; прецедент: D1=0.95/D2=0.80, ADR-171).
- Обоснование: SM&CR прямо строит режим вокруг персональной ответственности SMF-держателей; SMF1 несёт
  overall responsibility — «sole accountable executive» совместим с UK EMI-режимом при условии сохранения
  двух структурных исключений (SMF17, SMF5 — уже канонизированы в org-chart-v2 §2.2/§4) и оговорок C1/C2.
- **C1 (обязательная):** единоначалие действует ЧЕРЕЗ делегированные SMF-мандаты — делегирование НЕ
  переносит и НЕ отменяет персональную регуляторную ответственность каждого SMF-держателя в его зоне
  (SM&CR duty of responsibility). CEO = единый распорядитель; персональная accountability SMF-линейки
  перед FCA сохраняется параллельно.
- **C2 (обязательная):** зарезервированные вопросы Board (назначение/снятие CEO, утверждение стратегии и
  risk appetite) остаются за Board; CEO подотчётен Board/собственнику — единоначалие исполнительное,
  не над-Board'ное.

## Принцип (NORMATIVE)

1. **CEO (SMF1, человек — Moriel Carmi) = ЕДИНОЛИЧНЫЙ РАСПОРЯДИТЕЛЬ** и высшее лицо, принимающее ВСЕ
   управленческие решения банка; несёт всю ответственность перед Board/собственником.
   **«Sole accountable executive / единый распорядитель».** (С учётом C1/C2 выше.)
2. **ВСЕ департаменты, department-heads и агенты ПОДЧИНЯЮТСЯ CEO** — единая исполнительная вертикаль
   (Level 0 Board → L1 → L2 heads(8) → L3 → L4; org-chart-v2 §8).
3. **ИСКЛЮЧЕНИЯ — только две независимые линии (structurally separate, org-chart-v2 §4):**
   **MLRO/Financial-Crime (SMF17)** — SAR/финпреступность: SAR-authority только MLRO (I-12);
   SAR-retraction/sanctions-reversal — совместно с CEO. **Internal Audit (SMF5)** — подотчётен
   Audit Committee/Board. Только эти две линии не подчинены CEO в своих мандатах.
4. **КОЛЛЕГИАЛЬНОСТИ НЕТ:** комитеты (ALCO, Risk, Audit) только ГОТОВЯТ решения; окончательное решение и
   ответственность — CEO (или независимый SMF в его мандате). CEO председательствует в ALCO + Risk
   Committee (ORG-STRUCTURE §2.1).
5. **РАЗГРАНИЧЕНИЕ ЧЕЛОВЕК/АГЕНТ** (согласовано с D-2 / I-27 / I-28 / BOUNDARY §7 v2 — не нарушая их):
   - Право **РЕШАТЬ** = у CEO-человека (и независимых SMF в их зоне).
   - Право **ИСПОЛНЯТЬ по решению CEO** = у агентов, каждый в своей зоне; best-decision = метод
     ИСПОЛНЕНИЯ решения оператора (BOUNDARY §7 variant-2), внутри HITL-порогов, I-27 PROPOSES-only,
     I-28 CEO STOP-check.
   - **`ceo_orchestration_agent` = ИНСТРУМЕНТ CEO** (готовит/координирует/предлагает), НЕ автономный
     решатель и НЕ авто-исполнитель за других агентов (ADR-164 D-2 сохраняется полностью).
6. **Соотношение с инвариантами автоматики:** этот канон УСИЛИВАЕТ управленческую роль CEO, но НЕ отменяет
   и НЕ ослабляет D-2 / I-27 / I-28 / BOUNDARY §7 — те инварианты про автоматику и безопасность
   исполнения, данный канон — про управленческую иерархию. При видимом конфликте применяется более
   ограничительная норма (fail-closed).
