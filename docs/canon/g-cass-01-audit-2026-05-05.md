## 2. Findings

### Finding 1 — AuditTrail.log() is fail-open (CRITICAL)

**File:** `src/safeguarding/audit_trail.py` lines 113–132  
**Severity:** CRITICAL  
**Regulatory exposure:** FCA CASS 15 §15.10, DORA Art.14(2)

`AuditTrail.log()` wraps `_write()` in a bare `try/except Exception`. On any
exception from the ClickHouse HTTP call (network timeout, OOM eviction, container
restart), the exception is caught, an error is emitted to `stderr`, and `False` is
returned. The calling `ReconciliationEngine` receives no error signal and completes
successfully.

```python
def log(self, event: AuditEvent) -> bool:
    try:
        return self._write(event)
    except Exception as exc:
        logger.error(
            "AuditTrail FALLBACK — ClickHouse write failed (%s). "
            "Event NOT persisted. This is a compliance risk.",
            exc,
        )
        return False  # caller unaware of loss
```

The `_write()` method (line 134) makes a synchronous `httpx.post()` to
`http://192.168.0.72:8123` with a 5-second timeout (line 173). There is no retry
logic, no buffer, no dead-letter queue.

**Impact:** Any ClickHouse outage (rolling update, OOM, disk pressure) creates a
window where FCA CASS 15 §15.10 reconciliation events are silently dropped.

### Finding 2 — Default constructor uses dry_run=True (HIGH)

**File:** `src/safeguarding/audit_trail.py` line 104  
**Severity:** HIGH

`AuditTrail` defaults to `dry_run=True`, which disables all ClickHouse writes.
Any code path that instantiates `AuditTrail()` without explicitly passing
`dry_run=False` and a valid `clickhouse_url` produces no audit records whatsoever.
Production deployment correctness depends entirely on the caller supplying the
correct constructor arguments.

### Finding 5 — recon_engine.py Protocol DI is correct but unwired in production (MEDIUM)

**File:** `services/recon/recon_engine.py` lines 39–99  
**Severity:** MEDIUM

The core `ReconciliationEngine` correctly uses the Protocol DI pattern:

```python
class ReconAuditPort(Protocol):
    def record(self, entry: ReconAuditEntry) -> None: ...

class ReconciliationEngine:
    def __init__(self, audit: ReconAuditPort | None = None) -> None:
        self._audit = audit or InMemoryReconAuditPort()
```

When `audit=None` is passed (the default), the engine silently uses an in-memory
stub. There is no confirmed production wiring to `AuditTrail` via this interface.
A production deployment without explicit `audit=` injection produces no ClickHouse
records from the reconciliation engine.

## 3. Fail-Mode Summary

| Scenario | Current behaviour | Regulatory consequence |
|----------|-------------------|----------------------|
| ClickHouse down during recon | `AuditTrail.log()` returns False; recon completes | Audit event silently lost — CASS 15 §15.10 gap |
| ClickHouse down for >5s | httpx timeout; exception caught; False returned | Same as above |
| safeguarding-engine deployed | NotImplementedError raised on all audit/recon calls | Zero FCA records produced by SE service |
| ReconciliationEngine with audit=None | InMemoryReconAuditPort used silently | Zero durable records; in-memory buffer lost on process exit |

## 5. ClickHouse Infrastructure Posture

**ClickHouse on evo1 (192.168.0.72:8123):**
- Single-instance container — no replica, no HA
- No write-ahead buffer above OS filesystem layer
- Scheduled maintenance windows expected (rolling update, backup cron)
- Uptime verification from WSL2 shell: not accessible (network boundary)

**Risk:** Any single ClickHouse outage creates a compliance evidence gap.
Duration of gap = duration of outage. CASS 15 §15.10 requires evidence of
**every** daily reconciliation; a gap is a reportable failure.

## 6. Remediation Path

The remediation is specified in **ADR-027** (decisions/ADR-027-audit-trail-durability.md).

Recommended option: **Option (b) — async SQLite ring-buffer (BufferedAuditPort)**,
implemented in two phases:

| Phase | Action | Priority |
|-------|--------|----------|
| Immediate | Add `AUDIT_FAIL_CLOSED` env flag to `AuditTrail` | P0 |
| Sprint 4+ | Implement `BufferedAuditPort` conforming to `ReconAuditPort` Protocol | P0 |
| Sprint 4+ | Implement `audit_logger.py` in safeguarding-engine (remove NotImplementedError) | P0 |
| Sprint 4+ | Wire `ReconciliationEngine(audit=BufferedAuditPort(...))` in production entry points | P0 |
| Sprint 4+ | Add CI smoke test: CH-down → event in SQLite → drain → CH | P0 |
