# Approval Rules

## Автоматически одобрено (выполнять без запроса):
- git add / commit / push -- ДА
- pytest / ruff / semgrep -- ДА
- rsync к серверам (GMKtec, NucBox) -- ДА
- Создание файлов и директорий -- ДА
- Редактирование файлов -- ДА
- Запуск Docker-контейнеров -- ДА

## Требует подтверждения CEO:
- Удаление файлов -- СПРОСИТЬ
- Удаление репозиториев -- СПРОСИТЬ
- Изменение прав доступа -- СПРОСИТЬ
- Финансовые операции -- СПРОСИТЬ

## Правило продолжения:
Разработчик ОБЯЗАН продолжать работу без остановки на вопросы,
КРОМЕ случаев из списка "Требует подтверждения".

## Правило неоднозначности (best-decision)
Для задач, не входящих в whitelist «Автоматически одобрено» и не подпадающих под «Требует подтверждения CEO» / safety-rules / governance stop-барьер (CLAUDE.md §1, §11), Claude Code применяет принцип best-answer / best-decision: выбирает оптимальное решение самостоятельно и продолжает работу без встречного вопроса к CEO. Встречный вопрос допустим ТОЛЬКО при реальном риске потери данных, необратимости операции или нарушения инвариантов I-21..I-28.
