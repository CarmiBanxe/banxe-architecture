- **Decision:** Created `docs/adr/ADR-141-self-healing-continuous-learning-loop.md` (PROPOSED, concept_only) defining a **bounded, ASYNCHRONOUS, scheduled, HITL-gated self-healing continuous-learning loop** for factory AI employees — **NOT ungated self-modification**. Production sessions run FROZEN skills and NEVER self-modify; learning happens OFFLINE; every candidate revision is held-out-validated (ADR-135), versioned (ADR-137), operator-adopted. **Loop:** (1) episode capture (CI/spec/build/gate/tool-I/O/incident/benchmark signals) via ADR-136 agentmemory factory fork, redacted-at-capture (PRECOND-01); (2) redacted memory synthesis pipeline (bounded by PRECOND-01/02/03; ledger ADR-059 = source of truth); (3) observer/reflector role (read-only, Hermes Tier-1 ADR-126/127 → candidate findings); (4) analyst/evolution role (bounded edits, ADR-135 textual-learning-rate → candidate revisions, proposal-only); (5) **allowed mutation targets:** skills, prompts, runbooks, routing, pre-checks; (6) **prohibited targets (fail-closed):** authority (PRECOND-07/ADR-130), sensitive banking write paths (payment/KYC/AML/sanctions/ledger, RED zone PRECOND-06), raw secrets, raw PII memory (PRECOND-01), the held-out/benchmark sets + CI gates + canon ADRs (no self-grading/gate-weakening); (7) **held-out + benchmark gate:** adopt ONLY if ADR-135 held-out gate passes (strict improvement, zero boundary/safety regression) AND benchmarks (promptfoo-eval, adversarial-sim) show no regression — else rejected fail-closed; (8) **rollback/blame/versioning:** ADR-137 Memoir (branch/commit/blame/rollback) + ledger record per revision, every revision reversible to known-good; (9) **cadence:** nightly (light: capture+synth+reflect, no adoption) / weekly (heavy: proposals→ADR-135 gate→operator HITL adoption ADR-128 L2/L3 + IronClaw for sensitive-adjacent→versioned).
