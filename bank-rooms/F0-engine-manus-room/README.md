# F0 / engine-manus-room — BANKSY ENGINE (BANK CORE, heart)

**Engine name: BANKSY ENGINE** (formerly "ENGINE-MANUS"). Manus-like agentic engine compiled on open-source (OpenManus base + LangGraph/A2A/MCP/LiteLLM). Path kept as `F0-engine-manus-room` for stability.
**Status:** concept + parts exist, **NOT assembled into a single stack**. Core layer beneath floors 1–4.
See: `BANKSY-ENGINE-STACK-REGISTRY.md` (full stack) · `BANKSY-ENGINE-INTEGRATION-PLAN.md` (assembly plan).

## Why F0
The heart is not one of the 17 departmental rooms — it sits **beneath and across** all of them. `F0` denotes the core layer under floors 1–4: it serves every department and contacts the client directly. (Alternative name considered: `F2-core`; `F0-engine-manus-room` chosen because the heart spans all floors, not just F2.)

## The two roles
1. **Chief conductor (CEO-brain):** knows the full bank structure and technology; coordinates every department head so the bank runs like a Swiss watch — precise and consistent.
2. **Client personal-manager & friend:** resolves each client's questions across bank functions and helps/suggests solutions within a friendly relationship.

## The four layers
- **Layer A — shell (sub-modules absorbed into the heart):** swarm agents, design-pipeline UI agents, fx, webhook — the 12 helper "label-heap" files pulled **inward**, not distributed to other rooms.
- **Layer B — orchestrator:** the coordination brain (graph sandbox, tier routing, swarm/design/SCA orchestrators, midaz MCP, budget gate).
- **Layer C — client-PM:** the client-facing surface (intent, support, notifications-hub, quant-advisory routers + service).
- **Layer D — substrate:** the safety/observability floor (intent-layer canary/composition/observability/shadow, lineage/recorders, guardrails config).

## Relationships
- **Heart ↔ 17 departments:** the conductor coordinates all room heads (F1–F4, 129 bank agents) — see `../../docs/governance/AGENT-REGISTRY-BANK-MASTER-2026-07-22.md`.
